# IT Knowledge Base Website

Created by Jamie Pascual

A searchable IT support knowledge base built with HTML, CSS, and JavaScript. The website gives users a browser-based reference tool for common help desk issues such as password resets, VPN problems, printer issues, slow computers, email profile errors, software requests, Wi-Fi problems, and phishing reports.

## Features

- Searchable troubleshooting articles
- Category filters for Accounts, Networking, Hardware, Software, and Security
- Quick action cards for common issues
- Article detail panel with symptoms, resolution steps, and escalation notes
- Priority labels for support triage
- Responsive layout for desktop and mobile screens
- No external libraries required

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Responsive Design
- JavaScript Arrays and Objects

## How It Works

The project stores knowledge base articles in a JavaScript array. Each article includes a title, category, priority, symptoms, troubleshooting steps, and escalation guidance. JavaScript filters the article list based on the selected category and search text, then updates the page dynamically.

## How to Run

Open `index.html` in a web browser.
